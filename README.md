# Aevia Support

Public support and privacy pages for **Aevia: Life OS**.

Once GitHub Pages is enabled for `main` / `(root)`:

- Support: https://tmdgurqor0-code.github.io/Aevia-support/
- Privacy: https://tmdgurqor0-code.github.io/Aevia-support/privacy.html

## Enable GitHub Pages

Repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

The repository is public so the App Store support and privacy URLs can be opened without signing in.
